# Real-Time Collaborative Code Editor

A real-time collaborative code editor where multiple users can write and edit code simultaneously.

## Features
- Real-time collaboration
- Multiple users editing together
- User presence tracking
- Conflict-free editing using Yjs

## Tech Stack
- React.js
- Node.js & Express.js
- Socket.IO
- Yjs
- Monaco Editor

## Setup

### Frontend
npm install  
npm start  

### Backend
cd server  
npm install  
node index.js
